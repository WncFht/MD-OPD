## sampled token direct kl

```
bash recipe/opd.sh
# ...-sampled_adv_direct-T_1.0-...
```

对 rollout 中实际采样出来的 token `y_t`，teacher 和 student 的 log-prob
分别为 `log p_T(y_t)`、`log p_S(y_t)`。逐 token 的 reverse-KL（k1）reward 为：

```text
r_t = -(log p_S(y_t) - log p_T(y_t))
    = log p_T(y_t) - log p_S(y_t)
A_t = r_t
```

## top k reverse kl

```
LOG_PROB_TOP_K=16 bash recipe/opd.sh

```

令 `C_t` 为当前 token 的 top-k candidate 集合。对每个候选 `c`，先计算：

```text
d_t(c) = log p_T(c) - log p_S(c)
```

再按 `REWARD_WEIGHT_MODE` 生成权重 `w_t(c)`。以默认的 `student_p` 为例：

```text
w_t(c) = p_S(c) / sum_{c' in C_t} p_S(c')
r_t(c) = w_t(c) * d_t(c)
A_t(c) = r_t(c)
```

`TOP_K_STRATEGY` 决定 `C_t` 是 student/teacher top-k、交集、并集或对称差集；
因此 top-k reward 的张量形状是 `(B, T, K)`（并集策略可能有更大的 candidate 维度）。

## sampled token discounted kl

```
DISCOUNTED_TOKEN_REWARD=True GAMMA=1.0 bash recipe/opd.sh

DISCOUNTED_TOKEN_REWARD=True GAMMA=0.95 bash recipe/opd.sh
```

discounted 模式不是 GAE，而是零 value baseline 的 reward-to-go。沿 response
维度从后往前递推：

```text
A_{T-1} = r_{T-1}
A_t = r_t + gamma * A_{t+1},  t = T-2, ..., 0
```

response mask 外的 reward 会先置零，`gamma` 必须在 `[0, 1]` 内。若同时启用
top-k，则上述 `r_t` 和 `A_t` 的最后一维保留 candidate 维度。
