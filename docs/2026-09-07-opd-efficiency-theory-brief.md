## 1. 问题背景（最小版）

### 1.1 OPD 的目标与梯度

冻结一批学生自己采样的状态 $\mathcal S$ 后，OPD 是一个固定经验目标：

$$
J(\theta)=\mathbb E_{s\in\mathcal S}\,\mathrm{KL}\big(\pi_\theta(\cdot\mid s)\,\|\,\pi_T(\cdot\mid s)\big),
$$

梯度用逐 token advantage $A_i=\log\pi_T(y_i\mid s_i)-\log\pi_\theta(y_i\mid s_i)$ 估计（dense 信号、教师项不反传；完整梯度含 advantage 后缀和，实践用 immediate-token 近似）。这与 DAgger/MiniLLM/GKD 同源，但它是**学生采样状态上的 reverse-KL**，不是普通监督 CE——其局部曲率因此主要是 token 分布的 Fisher/GGN 结构。两个度量：$d_t=\mathbb E|A|$（论文 L1 口径）或逐 token KL（我们日志代理），吸收率 $v_t=(d_t-d_{t+1})/d_t$。

### 1.2 要解释的四个经验事实（Fu et al. 2026）

1. 吸收率 $v_t$ 随训练单调下降：300 步只吃掉 step-30 距离的 ~80%（$d_{300}/d_{30}\approx0.16$–$0.22$，四个数据规模一致）。
2. 节奏与数据规模无关：1 题与 17k 题同速（我们的数据补一条：token 子集 top-16 vs sampled-token 也不改节奏）。
3. 学习率只重标定时间轴：lr $\times\{0.5,1,2\}$ 按 $u=\eta t$ 折叠后曲线重合到 ~1.1×。
4. 冻结状态集后仍稳定对齐 ~200 步才进入平台。

(2)(3)(4) 把解释对象钉死为：**固定目标上的参数空间优化动力学**。瓶颈不在状态供给、不在测量漂移、不在梯度冲突——在优化本身。

### 1.3 效率问题

OPD 的长尾是优化性质，不是数据性质。这就是提升效率的切入点：如果吸收节奏由谱结构和优化器决定，那么改预条件、方差、步长调度就应该能改节奏——问题是用哪个杠杆、能改多少、代价是什么。EffOPD 用启发式外推已拿到 ~3×，说明空间存在；理论的任务是把"哪个杠杆动哪个量"讲清楚。

## 2. 最小推理链（谱吸收模型）

### 2.1 三个前提

**C1** 固定状态集（目标固定）；**C2** 局部二次化（reverse-KL 的 Hessian = Fisher，softmax 下 GGN=Fisher 精确成立）；**C3** 一阶更新 + 预条件近似常数（$\delta_{t+1}\approx(I-\eta PH)\delta_t$）+ 谱准静态。

### 2.2 推理链

1. **模式解耦**。$He_i=\lambda_ie_i$、$\delta=\sum_ix_ie_i$ $\Rightarrow$ $x_i(t+1)=(1-\eta\lambda_i)x_i(t)$，剩余误差
    $$
    d(t)=\sum_i a_i e^{-\eta\lambda_i t},
    $$
    即初始振幅加权谱的 Laplace 变换（对数距离曲线 = 谱测度的累积量生成函数）。
2. **吸收率 = 剩余误差的平均曲率**。$v_t\simeq\eta\langle\lambda\rangle(t)$，权重 $w_i(t)\propto a_ie^{-\eta\lambda_it}$。高曲率模式先耗尽 → 谱质心下移 → $v_t$ 下降。
3. **精确动力学（指数倾斜）**。$w(\lambda,t)\propto w_0(\lambda)e^{-\eta t\lambda}$，且
    $$
    \frac{d\langle\lambda\rangle}{dt}=-\eta\,\mathrm{Var}_{w(t)}(\lambda)\le0.
    $$
    即**"$v_t$ 下降"是定理**（指数混合必有递减风险率，Proschan 1963），不需要新机制来解释；定量形状（幂律 / 带边弯曲 / 平台）才携带谱结构信息。
4. **恒等式**：$\alpha(t)\equiv-\frac{d\ln d}{d\ln t}=t\cdot v_t^{\rm inst}$，$v_{50}/v_{200}=4\,\alpha_{50}/\alpha_{200}$。log-距离面板与 log-吸收率面板携带同一信息，不独立。
5. **噪声底与可吸收阈值**。每模式 OU 平衡 $\mathbb E[x_i^2]_\infty\approx\eta\sigma_i^2/(2\lambda_iB)$；KL 型距离的底
    $$
    d_\infty^{\rm KL}=\frac{\eta}{4B}\sum_i\sigma_i^2+d_{\rm gap}
    \qquad(\text{逐模式曲率恰好消掉}),
    $$
    可吸收阈值 $\lambda_{\rm crit}=\frac{\sigma_i}{c_i}\sqrt{\eta/(2B)}$：**谱中 $\lambda<\lambda_{\rm crit}$ 的监督，无论喂多少数据都吃不到**。
6. **白化极限**。恒定吸收率 ⟺ 自然梯度（$F^{-1}\nabla J$，每方向同速收缩）。但白化受信噪比限制：需要 $\sqrt B\,c_i\lambda_i/\sigma_i\gg1$——与 $\lambda_{\rm crit}$ 是同一个阈值；$\lambda\to0$ 处逆预条件方差爆炸，damping 不可避免（Martens 2014）。

**一句话模型**：OPD 训练 = 沿曲率谱从高到低逐模式吸收；瞬时节奏 = $\eta\times$剩余谱质心；尾部 = 低曲率端 + 噪声底；数据只改振幅不改节奏；lr 只改前进速度不改形状。

### 2.3 模型直接命中的预言

- **lr 折叠**（Laplace 变换只通过 $\eta t$ 依赖参数）——论文附录 C.2 命中到 ~1.1×。
- **数据规模无关**（节奏是 $\eta\lambda$ 谱的属性，数据改 $a_i$ 总量）——论文 §5.2 命中。
- **冻结态行为**（可吸收模式集合固定 → 全部均衡后进入硬平台 $d_\infty$；on-policy 不断把质量注回剩余模式，所以不停）——论文 §5.3 命中方向。

## 4. 效率杠杆地图（理论 → 优化算法）

统一语法：**任何优化干预 = 修改从 $\{\lambda_i,a_i,\sigma_i\}$ 到有效速率 $\{\eta\lambda_i^{\rm eff}\}$ 与底 $d_\infty$ 的映射**。三个互不替代的旋钮：谱形状压缩（$\lambda^{\rm eff}$ 动态范围）、可吸收集合（$\lambda_{\rm crit}$）、终态底（$d_\infty$）。

| 杠杆                                         | 机制                                                                                                                    | 能改                                              | 不能改                                                                            | 状态                                                                        |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 预条件/白化：Muon、SOAP、K-FAC、Shampoo      | 压缩 $\{\eta\lambda_i^{\rm eff}\}$ 动态范围                                                                             | $v_t$ 形状、$\alpha$、中段吸收速率                | $\lambda_{\rm crit}$ 与信噪比底                                                   | M6 待做（H6：若 $\alpha$ 跨优化器不变，指数是损失几何性质，此杠杆收益下调） |
| 方差工程：末期升 batch、权重 EMA/Polyak 平均 | 把 $\lambda_{\rm crit}$ 推向谱深处                                                                                      | 可吸收模式集合、$d_\infty$                        | 谱形状                                                                            | P2 未启动                                                                   |
| 吸收率闭环步长（P1）                         | $v_t$ 是 $\langle\lambda\rangle$ 的在线读数；活性曲率衰减 ⇒ 稳定性上限放松 ⇒ lr 应随 $d$ 下降而升（标准调度的时间反演） | 沿同一条形状曲线超线性前进                        | 底 $\propto\eta$，必须配方差工程                                                  | 等 M3/M4 修好读数                                                           |
| 谱方向外推 / 低秩谱预条件（Spectral EffOPD） | 早期方向锁定（驱动力 $b=\mathbb E[J^\top F r]$ 集中于少数特征方向）→ 沿主子空间外推或谱线搜索                           | "方向已对、幅度不足"阶段的步数（EffOPD 已报 ~3×） | 底；$b_i\approx0$ 的方向                                                          | M5（Lanczos 测 $\{\lambda_i,x_i\}$）是升级为可验证工程的前提                |
| token 加权（P4）                             | 给高信号 token 更高早期速率                                                                                             | 早期 $v$、同质量 run 长度                         | 指数；须退火到无偏或重要性校正，否则移动不动点（收敛到加权 teacher 而非 teacher） | 未启动                                                                      |
| $d$ 预算停止准则（P6）                       | $d(t)\sim t^{-\alpha}+d_\infty$ ⇒ 边际收益可预测                                                                        | 算力分配决策                                      | —                                                                                 | 随时可做                                                                    |

两条反直觉推论（立字为据）：

1. **更大的 batch 不是缩短 run，而是吃得更深**——可见 run 可能变长，但同 step 数的终态 $d$ 更低。
2. **预条件子赢不了平坦方向**——$\lambda<\lambda_{\rm crit}$ 的监督不是"没用"，是"这个优化器在这个 batch 尺寸下吃不到"；换更好的预条件子不能替代降方差。

EffOPD 的定位（源文档 3）：论文测的是**更新矩阵的欧氏 SVD** 低秩与任务性能；升级为谱理论需要两个证据：(i) 更新主奇异子空间与 $A=\mathbb E[J^\top FJ]$ 特征子空间对齐；(ii) 驱动力振幅 $b_i$ 集中在这些方向。其 50 样本验证 ≈ 轻量信赖域/线搜索；验证接受 ≠ 真实目标一定下降。

## 5. 理论边界

### 5.1 已确立

- $v_t$ 下降 = 宽谱 + 一阶优化的定性定理；两个可检验预言（lr 折叠、数据无关）已命中。
- 论文 L1 口径：四条曲线全部幂律最优（$\alpha\approx0.44$–$0.67$，无系统漂移）——"幂律谱×幂律振幅"在 L1 口径仍是可用近似。
- 我们 KL 口径：$\alpha$ 上升 0.7→1.3 + step~55–80 凸起；凸起锚定在优化器步数（不随 lr 折叠缩放，支持 Adam 瞬态机制 H3a），且 KL 代理的 CE−H 相减是主要嫌疑——跨口径差异收敛为口径问题，M3 裁决。
- M2（NNLS 谱反演）单 seed 版完成：KL 曲线需带弯曲的多模式谱外推更好，论文 L1 曲线纯幂律更好——两口径各自自洽，反演按口径换算。

### 5.2 待裁决（测量程序，见源文档 1 §6）

| 项                                            | 回答的问题                                                                         | 状态 |
| --------------------------------------------- | ---------------------------------------------------------------------------------- | ---- |
| M3 逐 token 日志（1 run，**最优先**）         | 三口径（L1/KL/CE）同 run 拆解——所有跨口径悬案的总开关                              | 未做 |
| M4 Adam 消融（5 run）                         | $\beta_2$/$\epsilon$/lr/sharpness 探针——凸起归因（H3a/b/c）与软底                  | 未做 |
| M5 冻结态 Lanczos（1 run + 探针，**决定性**） | 测 $\{\lambda_i,x_i\}$，零训练预测整条 $d(t)$；量化谱漂移速率                      | 未做 |
| M6 优化器消融（2–4 run）                      | $\alpha$ 是损失几何性质还是优化器性质 → 决定白化杠杆的预期收益                     | 未做 |
| D2 底标度（6 run）                            | $d_\infty\propto\eta/B$（KL）vs $\propto\sqrt{\eta/B}$（L1）；噪声底与表示缺口分离 | 未做 |

### 5.3 根本性未知（本框架不回答）

1. **谱为什么长这样**：架构×目标几何的起源问题。部分故事：NTK 谱按频率多项式衰减、F-Principle/谱偏差、数据侧 quanta 结构（Michaud 2023）。
2. **on-policy 反馈闭环**：学生更新 → 状态分布漂移 → Hessian 加权漂移，无理论；冻结态实验只证明它对 pace 是二阶效应。
3. **时变谱的倾斜动力学**（$\lambda_i(t)$ 进场）是模型的自然扩展，未做。
4. **任务谱 ≠ 裸谱**：SLQ 的 trace-weighted 谱密度不能直接解释 $v_t$，必须配任务振幅（$b_i$ 或 $x_i$）。
5. **估计论下界**：随机凸优化 $O(1/t)$ 型极限——要往底以下走必须降方差，算法聪明绕不过。

## 6. 给后续工作的守则

1. **先修读数，再谈干预**：$v_t$ 目前含非谱成分（凸起、熵污染）；M3 之前，任何以 $v_t$ 为反馈的控制器的信号不可信。
2. **同口径比较**：$\alpha$、$v_{50}/v_{200}$ 只在同一种 $d$ 定义内自洽；跨口径只读方向不读数值。
3. **按"改映射"归档新想法**：每个效率想法先回答它动的是 $\{\lambda_i^{\rm eff}\}$、$\lambda_{\rm crit}$ 还是 $d_\infty$——三个旋钮不可互相替代，组合才有叠加收益。
